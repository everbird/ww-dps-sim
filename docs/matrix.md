# 矩阵（终焉矩阵 · 奇点扩张）怎么计分、两队怎么排（2026-10-22）

定位：检验仿真引擎的一个具体场景，辅助用；项目的重点是引擎本身。

`pnpm matrix <场景.yaml …> [--stage 矩8] [--md 输出.md]`（`src/engine/matrix.ts`），数据 20261019 版。

## 规则从哪来

用户说矩阵按伤害算分，并推荐了 [DPM-Team-Builder](https://indychen.github.io/DPM-Team-Builder/)（鸣潮矩阵编队工具，[仓库](https://github.com/IndyChen/DPM-Team-Builder) 只有打包后的网页，没有源码）。
下面的规则与缺省值是从它 v4.9.2（2026-10-14，"终焉矩阵 S2-3（3.7 版）"）打包后的代码里读出来的：

| 项 | 值 | 备注 |
|---|---|---|
| 每队限时 | 120 秒 | 进场 1 秒、每打死一只转场 1.5 秒都算在里面 |
| boss 顺序 | 每轮 5 只，第 5 只是矩阵奇藏；R1 → R2 → R3 → R4 … | 上一队没打完的，下一队接着打剩下的血 |
| 得分 | 每万点伤害 × 轮次倍率 | R1 8.34、R2 9.60、R3 起 10.43；第 5 只 × 1.1（9.18 / 10.55 / 11.47，按 DPM 的取整） |
| 击杀奖励 | 打死第 5 只 +1000 | 其他几只没有 |
| 伤害上限 | 打到剩余血量为止 | 溢出、转场期间的伤害不算 |
| 血量 | R1 561.25 万、R2 954.15 万、R3 1938.9 万；奇藏 R1 617.38 万、R2 1275.61 万 | R4 起按 R3 每只 +5%（单利：第 n 只 × (1 + 0.05n)） |
| 出场次数 | 一般角色 1 次，生存位 2 次 | `pnpm matrix` 只查"角色不重复"，不分生存位 |

**和我们的数据对上了**：DPM 的血量表与敌人表的"矩8"（燎照之骑、封庭械囿、无冠者、天傀劫煞、矩阵奇藏，R1 / R2 / R3 是 100 / 110 / 120 级）逐只一样，到小数点后 4 位（第 2 只封庭械囿是 561.2723 万，别的 561.2519 万）。所以 S2-3 就是"矩8"。"矩1R4"也是按 R3 每只 +5% 单利涨的，和 DPM 的外推一致。

DPM 的环境设定里抗性那一栏是空的（缺省不减伤），它的 DPS 是"每秒几万"、从实战或社区轴来的；我们按敌人表的抗性、等级逐只算。

## 怎么算

1. 每支队对这一期每只 boss 各跑一次仿真（换敌人预设，循环轴加跑到够 119 秒）。
2. 按这一队的计时接力：第 1 只从第 1 秒起吃"对它那次仿真"的命中，累计到剩余血量就打死；下一只 1.5 秒后出来，从那一刻起吃对它那次仿真的命中。
3. 120 秒到了换下一队，接着打剩的血。每种出场顺序都跑一遍，按总分排。

假设 `matrix-relay`（`pnpm assumptions` 能看到）：
- 轴不因换 boss 停顿：打死后照着轴继续放，转场里打出去的作废。
- 敌人身上的状态（偏谐、异常效应层数、白条）按"这只 boss 从开场就在"算，换 boss 时没清空。心队的电磁效应层数在敌人身上，这条对它影响可能比 M0 大。
- 限时按战斗秒（大招的全局时停也停表）。
- 每轮 5 只按敌人表的顺序出场。

## 两队打"矩8"

| 出场顺序 | 总分 | 比最好 | 两队总伤害 | 打到 |
|---|---:|---:|---:|---|
| **M0 视频轴 → 心队原轴** | **7,158** | 最好 | 858 万 | R1-2 剩 47% |
| 心队原轴 → M0 视频轴 | 6,816 | −4.8% | 817 万 | R1-2 剩 54% |
| M0 D1（维里奈 Q 后移）→ 心队原轴 | 7,188 | — | 862 万 | R1-2 剩 46% |
| M0 视频轴 → 心队原轴（卜灵武器精炼 5） | 7,820 | — | 938 万 | R1-2 剩 33% |

心队原轴是你账号的配置（卜灵武器奇幻变奏精炼 1）。

最好的顺序里每只怎么打的：

| 队 | boss | 血量 / 抗性高的 | 从（秒） | 到（秒） | 伤害 | 打死 | 分 |
|---|---|---|---:|---:|---:|---|---:|
| M0 视频轴 | R1-1 燎照之骑 | 561 万 / 热熔 40% | 1.0 | 120.0 | 417 万 | — | 3,478 |
| 心队原轴 | R1-1 燎照之骑 | 561 万 / 热熔 40% | 1.0 | 47.1 | 144 万 | 是 | 1,202 |
| 心队原轴 | R1-2 封庭械囿 | 561 万 / 冷凝 40% | 48.6 | 120.0 | 297 万 | — | 2,477 |

**读法**：
- **M0 先上**，多 4.8%。M0 的散华是冷凝，打冷凝 40% 抗的封庭械囿吃亏；先上就只打燎照之骑（热熔抗，对椿、散华都是 20%）。心队是导电，"矩8"这几只都不抗导电，排在后面打谁都一样。
- 两队都打不死一只 R1（120 秒 400 多万）。所以现在的分几乎就是"两队 238 秒的总伤害 × 8.34"：
  - 转场、奇藏击杀奖励、轮次倍率还用不上；
  - 提高分数就是提高对这几只的 DPS。D1 多 0.4%，卜灵武器精炼 5 多 9%。
- 换一期矩阵（boss 的抗性不同），先后可能反过来：哪队的元素被抗，就让它去打不抗它的那只。用 `--stage 矩7` 这样换期数。
- **和 DPM 的轴库比**：它库里"椿 · 散华 · 守岸人"是每秒 5.6 万，"椿 · 洛可可 · 守岸人"6.35 万。我们 M0 对燎照之骑约 3.5 万/秒，差别来自配装（DPM 的是社区高练度轴）、奶位（守岸人 vs 维里奈）和抗性口径，只能作参考。

## 以后可以做的

- **用你的实战分校准**：DPM 有"实战反推"，用实际得分反推每队的 DPS。你打一次矩阵，把每队的分数（或打到哪只、剩多少血）告诉我，我就能反推实际伤害，和仿真对照（比训练场测更省事）。
- 场地 buff（敌人表"矩阵叠兵"的效果文字）和局内加成还没算，和现在的做法正交，可以加。
- 第三支队定下来后，用 `pnpm matrix` 排三队的顺序（生存位出场两次还不分）。
- 不做：把接力做进仿真内核（换 boss 时清空敌人状态、打死后轴怎么接）。矩阵只是检验引擎的场景，为它改内核动得太大；接力保持事后拼接，差别记在假设 `matrix-relay` 里。
