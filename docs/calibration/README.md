# 实测与校准记录

总设计 §11 第 6 条：实测伤害数字、轴时长、半程切人拿到的能量和协奏，记在这里；发现偏差优先改 `rules` 里的规则表，而不是改引擎。怎么查对不上见 TD-11（`docs/wuwa-dps-td11-debug-calibration-v0.1.3.md`）。

## 放什么

- 一个文件对应一个参照（一段视频、一次实测），文件名 `<日期>-<主题>.md`，如 `2026-10-05-m0-video-25s.md`。
- 规则与数据的确认结论（"切人不退出盛绽"之类）照旧记在 `docs/m0-confirm.md`，这里只放带数字的对照。

## 每份记录写什么

```markdown
# <主题>

- **来源**：视频链接与时间点 / 实测（谁、哪天、什么版本）
- **条件**：队伍、链度、武器、声骸（或指向场景文件）、敌人、开局状态
- **场景**：scenarios/<场景>.yaml（含 video.marks 时注明对照第几轮）

## 数值

| 项 | 参照 | 仿真 | 差 | 备注 |
|---|---|---|---|---|
| 一轮时长（世界秒） | … | … | … | 时钟按 TD-11 §1.2 |

## 结论

- 对上了 / 差在哪一层（TD-11 §2）/ 未结，下一步
- 改了什么（规则表、场景、数据修正），对应的提交
```

## 视频时间点

写进场景的 `video` 段（TD-11 §6.3），用 `pnpm trace <场景> --md` 生成对照表；把生成的 Markdown（`out/` 下，不进 git）里要留的部分摘进记录。
