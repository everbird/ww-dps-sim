# 两队打深塔、矩阵的 boss 要多久（2026-10-22）

用 `pnpm sim <场景> --enemy <敌人> --goal kill:1 --repeat 24` 算（TD-10 §6.3），数据 20261019 版。单位：战斗秒（大招动画不计）。

**先看局限**：
- 每一层只当一个单体 boss 打。没算：
  - 同层的小怪、多波；
  - 深塔、矩阵的场地 buff（敌人表里有"逆境深塔""矩阵叠兵"的效果文字，还没做成运行时 buff）；
  - 时限、换层的切队；
  - boss 的阶段、锁血、无敌、转场。
- 所以绝对秒数偏长、只能横向比：同一只 boss 哪队打得快，同一队打哪只快。
- "深渊"就是逆境深塔（用户 2026-10-22 确认，敌人表的 `N塔中N`）；矩阵按伤害算分，几队接力、每队 120 秒，见 `docs/matrix.md`（`pnpm matrix`），比这里的单体击杀时间更贴近实战。"矩8"是现在这期（S2-3），R2 是 110 级、R3 是 120 级。

## 读法

- **心队（导电）**：
  - 打深塔中区 1 层这几只（湮灭、冷凝 60% 抗，导电只有 20%）都是 112～133 秒；
  - 哀声鸷血更厚（672 万），慢 20%；
  - 矩阵的朔雷之鳞导电 40% 抗，是心队最慢的一只。
- **M0（椿是湮灭）**：打湮灭 60% 抗的无常凶鹭、无冠者很吃亏（268 秒，是心队的两倍多）；打冷凝抗的辉萤军势也一般（166 秒），因为散华是冷凝。
  - 矩阵里湮灭 40% 抗的无冠者也慢（342 秒）。
  - 选层时 M0 该避开湮灭抗高的。
- **心队 C8 比原轴快 7%～18%**（越肉的越明显）；但 C8 要卜灵武器精炼 5，你账号是精炼 1（第三列，比精炼 5 慢约 10%）。
- 想更接近实战，下一步要：
  - 做深塔 / 矩阵的场地 buff；
  - 按一层的全部敌人算总血量（多目标的范围伤害仍不算）；
  - 按你实际用的配装重跑。
