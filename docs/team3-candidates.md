# 第三支队伍的候选：数据齐不齐（2026-10-21）

两个账号的库存里装满 5 件声骸、还没写模块的角色（椿、散华、维里奈、心、雷主、卜灵之外），按数据 20261019 版（资源版本 3.7.13）装配后还要处理多少，帮你挑队伍时参考。队伍、武器与阶数、文字轴由你定（4-4-1-1-1 的角色另说首位放哪件）。

- **待处理的推断值**：`pnpm check:data -- --flags <角色>` 列出的 flag（TD-01 §13.1）：没有结束帧、类别推不出、优先级变化帧凑不齐、多段次数是推的……写模块时逐条确认或写 `accept`。
- **没连上倍率的判定**：其中 `noDmg` 的判定行。不少是没有伤害的标记行（"聚怪""判断""下落"），确认后写 `dmg-join.json` 的 null；剩下的才是要补倍率的。数越小，写模块越省事。
- 没算进来的：角色机制本身的复杂度（形态、核心资源、钩子）。老角色（3.0 以前）多半机制简单、谐度破坏只造成伤害。
