## 2. 需要你拍板的事（M2 前定即可）

1. **维里奈 A3 默认按哪种情形算**：三行是互斥的，打单体 boss 时建议取"目标3m内"。其余两行会在装配时去掉。
2. **三人的共鸣链数**。同一个动作组里常有按链区分的几行，比如椿的大招有 C0 / C3 / C5 三行，装配时要按你的链数只留一行。链数也决定哪些共鸣链 buff 生效。
3. **散华 QTE 的优先级变化帧**：备注写"第42F可响应大招"，但数据没有给优先级变化帧，按规则回退到了派生帧 61。建议手写改成 42（即 QTE 第 42 帧起可以放大招打断）。你在游戏里有感觉的话告诉我。
4. **维里奈的 6 条治疗**（核心-治疗、大招-瞬间治疗、C0 / C3 协同治疗、延奏-治疗、C1-治疗）：dmg 里有倍率，但动作表里没有同名判定。治疗不影响伤害，M3 做"治疗时触发"类效果时再对应，M0 不处理。

## 3. 已按默认规则处理，M2 前我再逐个看（不用现在回）

装配时靠推断补上的地方都打了标记（TD-01 §13），三人共 40 处动作级、8 处判定级（都是散华谐度破坏数字行的"可脱手"缺省），主要是这几类：

| 类别 | 例 | 默认做法 |
|---|---|---|
| 优先级变化帧靠回退得出 | 散华 E [4, 2] 取派生帧 60；椿 QTE [11, 1] 取 71 | 按 TD-01 §13.1 的回退链 |
| 优先级缺变化帧 | 散华 A5 [2, 4, 2] 只知道第一段 | 截断成已知部分（TD-04 Q7） |
| 多个结束帧 | 椿 E3、QTE、大招；维里奈 A3、重击 | 取第一个 |
| 方向变体 -前 / -后 | 椿 盛绽·闪避 | 只取 -前 |
| 没有结束帧 | 椿 盛绽·待机、延奏；散华 蓄力 | 用判定与派生帧推算 |

这些大多只影响出招时机的一两帧，等 M2 跑单人轴、和游戏里对轴时长时一起校准。
