# 进游戏实验（DD-08 §5）

每项实验一页：`<题号>-<简称>.md`，题号与操作步骤以 `docs/verify-guide.md` 为准。这里定的是手册没写的四件事：**事先登记预测、录制、读数、入账**。证据闭环的记录在 `docs/evidence/`，观测在 `docs/calibration/points.yaml`。

## 先登记预测，再进游戏（DD-08 §5.2）

1. 写好实验页的前七栏与判据，写好 setup 小场景（`scenarios/evidence/`）与观测（`points.yaml`，读数留空）、闭环记录（`docs/evidence/<闭环 ID>.yaml`）。
2. `pnpm evidence predict docs/evidence/<闭环 ID>.yaml`：把预测填进闭环文件，抄进实验页的"预测"一栏。
3. 看命令打印的**区分度**：每条观测上各候选的接受区间（预测 ± 容差）两两不重叠才"可区分"；全都区分不了的实验先不做。容差不能小于读数精度。
   **再核对一遍 setup 与操作是同一件事**（C8 的教训）：操作写"一起手就连按"时，setup 里对应的是抢帧 `!`；缺省的 `A B` 是"等 A 出手再按 B"的打法，预测的是另一件事。
4. 提交代码与 setup 场景后 `pnpm evidence register docs/evidence/<闭环 ID>.yaml`（冻结预测运行的身份、观测定义与预测值的两个摘要），再提交闭环文件。之后不再改候选、判据与观测的容差，要改就另开一条闭环。
5. 进游戏做实验。

## 录制与读数（DD-08 §5.3）

- **录制**：60 帧、原始分辨率；HUD 全开（技能栏冷却、协奏环、回路条、敌人血条看得到）；训练场开伤害数字；每段录像开头念出或打出题号与第几次。录像放 `~/wuthering-waves/experiments/<日期>/`，文件名带题号。
- **按键记录**（可选）：有条件时同时开"跑轴记录"插件，按 `docs/okww-axis-notes.md` 的格式留一份按键时间。只借格式，不抄代码。
- **读帧**：逐帧截图放 `~/.cache/ww-frames/`。读"可见的现象出现的第一帧"（HUD 消失的第一帧、技能图标进冷却的第一帧、切人后新角色头像亮起的第一帧）。每个读数记成帧范围 `[最早可能, 最晚可能]`，再换成观测的 `gameRange`。
- **观测帧与模型帧分列**：实验页里录像帧号与换算出的模型帧各占一列，写明换算（起点对齐在哪个事件上）。不用模型里的 1–2 帧预先修正读数（路线图 §10.2）。
- **时钟**：录像数帧得到的是世界帧；深塔倒计时读的是战斗时钟。观测的 `clock` 照实填。
- **读不出来就写读不出来**：遮挡、掉帧、HUD 没刷新时，这次重复作废或把区间放宽，不靠猜。

## 入账

读数写进 `points.yaml` 对应观测的 `game` / `gameRange`（切人类型写 `expect`）与 `condition`（游戏版本、日期、与 setup 不同或不确定的条件）→ `pnpm evidence judge` → 人填采用决定 `decision` → `pnpm evidence rerun` → `pnpm evidence ledger` 把证据条目与结论贴进 `src/engine/propositions.ts` → `pnpm evidence --md`。

## 实验页的模板

| 栏目 | 写什么 |
|---|---|
| 命题与候选 | 台账里的命题 ID；每个候选写全条件 |
| 账号与配置 | 哪个账号；角色、链数、武器、声骸首位；与对应场景文件不同的地方 |
| 场地与敌人 | 训练场还是深塔哪一层；敌人、等级；环境效果 |
| 初态 | 能量、协奏、核心资源、形态、冷却；怎么把它摆成这样 |
| 操作 | 逐步的按键；引用手册的题号，不重抄 |
| 控制与重复 | 对照组是什么；每组做几次（缺省 3 次，DD08-Q5；改了写理由） |
| 录什么 | 见上面"录制与读数" |
| 读什么 | 每个观测怎么从录像里读出来，读成点值还是区间 |
| 预测 | 由 `pnpm evidence predict` 生成的表：每个候选、每个观测的预测值 |
| 判据 | 容差；怎样算支持、冲突、分不清 |
| 成本 | 操作、换号、重置、读数各估多少；实际花了多少（做完再填） |
| 结果 | 做完后填：观测 ID、读数、指向闭环记录 |
