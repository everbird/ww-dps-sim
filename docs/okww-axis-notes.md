# okww-axis 与「跑轴记录」：能借的东西（2026-10-28）

两个社区项目（作者楽山，AGPL-3.0，和 ok-wuthering-waves 一致）：

- [okww-axis](https://github.com/wk321425/okww-axis)：给 Claude Code 用的 skill，教人给 ok-ww（鸣潮自动战斗框架）写自定义战斗轴。里面有文档、7 个 Python 脚本和一条参考轴"心雷穗"（`Hsin.py` 2345 行，另有一个干跑用的假游戏）。目标是让游戏自己按轴打，靠读屏判断时机、实机反复调。
- [ok-ww-axis-recorder](https://github.com/wk321425/ok-ww-axis-recorder)：ok-ww 的插件"跑轴记录"，只能在 Windows 上用。每一局记成 JSONL：按键、在场角色、读屏读数、日志，外加每秒 4 帧的画面。

他们是"让游戏按轴打"，我们是"仿真期望伤害"，方向不同。重叠在四块：官方帧表、扒录像、读 HUD、心 · 雷主 · 卜灵的机制。**只借格式和实测的事实，不抄代码**（AGPL 会传染到我们的仓库）。

## 1. 已经用上的

- **HUD 隐藏多久**：他们实机量的雷主大招约 3.8 秒、转相 4.3、临寰宇 2.0、万阙垂天 5.0，和 xlsx「隐藏HUD」行一致。顺着这条，我们用中 4 录像逐帧量出：**HUD 消失的那一帧就是大招起手**，可以把起手钉到一帧；"HUD 回来"不等于能操作（镇寰宇隐藏 120 帧、全局时停 150 帧，下一个动作在 151 帧）。由此发现仿真把卜灵大招自己命中的顿帧算进了过场，切人晚 0.15–0.27 秒，引擎改了（`rules.hitstopInGlobalStop`，`docs/tower-20261026.md` 中 4 第 10 条）。
- **空中入场**：他们实测"切人落在上一个人离地的那一下，下一个人就是空中进场，开场普攻变成下落攻击"（卜灵因此先给震、不给艮）。中 4 第 4 段照这个写成卜灵空中攻击 → 雷山小过。
- **读心的回路条**（2026-10-28）：用下面 §2 的 `XN_GAUGE_L / R` 读中 3、中 4 的应世心，做成贴合度的一项（`video.core`，`docs/tower-20261026.md` 中 4 第 11 条）。由此查出轴里有几处补位普攻录像里没打。照世心、电涌还没读。
- **ffmpeg 裁剪的奇数宽高**：yuv420 的片子用奇数宽高裁剪时，ffmpeg 会悄悄取成偶数，按字节切帧就错位、时间往前漂。查过我们的帧工具，用过的裁剪框宽高都是偶数，没受影响。

## 2. 以后能用的

- **"人为操作"模式录训练场实验**：你自己打，插件用 Raw Input 记每个键按下 / 松开的时刻（`{"e":"in","t":秒,"a":动作,"k":键}`），每 0.25 秒读一次 HUD 认谁在场（`{"e":"field","i":位置号,"cnt":认到几个}`），表头有键位和队伍；配 N 卡即时重放时，它拿画面逐帧对出"录屏秒 = 记录秒 + offset"（`<这局>.video.json`）。这样切人、E、R、声骸的时刻直接是文字，不用逐帧看图；"按下"和"动作出手"的差正好是调度器关心的（被吞的键、预输入，他们写明"演出里按的键直接丢、不排队"）。要先有一份真实记录才能写导入（`video.events` / `marks` / `at` 的草稿）。限制：要装 ok-ww；在场每 0.25 秒一次；画面只有 960×540，跳字还得读原始录屏。
- **读 HUD 的框**（4K 坐标，1440p 乘 2/3）：心应世心条 `XN_GAUGE_L (1627,1999,1837,2011)` / `XN_GAUGE_R (1965,1999,2175,2011)`；照世心是统御众机里回路条的 8 颗雕像（x = 1647, 1719, 1794, 1866, 1938, 2013, 2085, 2160，y = 1980，被吃掉的翻面、中间出红菱形）；雷主电涌满 = 回路条右边 [E] 小框亮白字 `(2251,1993,2311,2016)`；"Q 图标整个变灰 = 在空中"。应世心已经读了（见 §1）；照世心、电涌还可以照样读。卜灵卦象栏的读法 `bl_gua()` 在他们没公开的另一条轴里。
- **数据勘误的线索**（以后的角色）：洛瑟菈长按 E 帧表"30~45F"不准、变奏入场给 100 印象（帧表写 50）；弗洛洛谱曲终末有 25 秒的隐藏冷却（按游戏时间走、大招演出里停）；卡提希娅重击起手 ≈ max(按下 + 0.3 秒, A4 起手 + 0.5 秒)。
- **心普通 E 最后一下主动引爆电磁效应**：和我们心模块的踏月归心一致，算互相印证；没解释踏月归心偏高。

## 3. 用不上的

- `frame_data.py`：读同一张 xlsx，我们的构建更完整。
- 引擎与宏的代码、ok-ww 框架的坑、干跑假游戏：解决的是"怎么按键"，不是"伤害怎么算"。
